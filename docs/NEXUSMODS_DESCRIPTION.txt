[size=5][b]OC2 Controller Icons[/b][/size]

On PC, Overcooked! 2 always shows Xbox buttons, no matter which controller you
use. This mod fixes that - and it works for couch co-op where every player
uses a different controller.

[size=4][b]Features[/b][/size]
[list]
[*][b]Universal menu prompts[/b] - every button prompt in menus becomes a
layout-agnostic icon: four circles (top / left / right / bottom) with the one
you must press filled in. Works for Xbox, PlayStation and Nintendo players at
the same time. Bumpers, triggers and sticks follow the same idea.
[*][b]Unbranded controls screens[/b] - the controller diagrams (Settings >
Controls and the pause menu) show a generic controller: no Xbox logo, empty
face buttons.
[*][b]Per-player in-game prompts[/b] - tutorial and kitchen prompts ("pick
up", "chop"...) use the layout chosen for each player: Xbox, PlayStation,
Nintendo or Generic. Shared prompts follow the chef standing closest to them.
Nintendo shows the correct physical button (bottom = B).
[*][b]Player select cards[/b] show each player's controller type (Xbox,
DualShock or Pro Controller silhouette).
[*][b]Native settings[/b] - a "CONTROLLER LAYOUTS" section at the bottom of
Settings > Game, with the game's own look, navigation, Save/Discard dialog.
[*][b]12 languages[/b] - follows the game language.
[*][b]Safe[/b] - no game files or save files are modified. Disabled by default.
[/list]

[size=4][b]Installation[/b][/size]
Find the game folder: Steam > right-click Overcooked! 2 > Manage > Browse local files.

[b]Windows[/b]
[list=1]
[*]Download [i]Windows_Linux[/i] and extract it into the game folder (next to Overcooked2.exe).
[*]Start the game from Steam.
[/list]

[b]Linux / Steam Deck (Proton)[/b]
The game has no native Linux build - Steam runs the Windows version through Proton.
[list=1]
[*]Extract [i]Windows_Linux[/i] into the game folder (next to Overcooked2.exe). On Steam Deck, do it in Desktop Mode.
[*]Steam > Overcooked! 2 > Properties > Launch Options:
[code]WINEDLLOVERRIDES="winhttp=n,b" %command%[/code]
[*]Play (Gaming Mode works too on Steam Deck).
[/list]

[b]Mac[/b]
[list=1]
[*]Extract [i]macOS[/i] into the game folder (next to Overcooked2.app).
[*]In Terminal, inside the game folder: [code]chmod +x run_bepinex.sh[/code]
[*]Steam > Overcooked! 2 > Properties > Launch Options:
[code]"$HOME/Library/Application Support/Steam/steamapps/common/Overcooked! 2/run_bepinex.sh" %command%[/code]
[*]If macOS blocks libdoorstop.dylib, allow it in System Settings > Privacy & Security
(or run [code]xattr -dr com.apple.quarantine .[/code] in the game folder).
[/list]

[b]Already using BepInEx 5?[/b] Download [i]PluginOnly[/i] and extract it into the game folder.

[size=4][b]How to enable[/b][/size]
[list=1]
[*]Main menu > Settings > Game.
[*]Scroll to the bottom, section [b]CONTROLLER LAYOUTS[/b].
[*]"Universal controller icons" > [b]On[/b].
[*]"Player 1-4 controller" > Xbox / PlayStation / Nintendo / Generic (default: Xbox).
[*]Press [b]Save[/b].
[/list]
Player numbers match the slots on the player-select screen. Keyboard players
keep seeing keyboard keys. Online, only your own screen is affected.

[size=4][b]Uninstall[/b][/size]
[list]
[*][b]Just turn it off:[/b] Settings > Game > Universal controller icons > Off.
[*][b]Remove the mod only:[/b] delete [i]BepInEx/plugins/OC2ControllerIcons[/i]
(and optionally [i]BepInEx/config/com.oc2mods.controllericons.cfg[/i]).
[*][b]Remove everything (Windows / Linux / Steam Deck):[/b] delete [i]BepInEx[/i],
[i]winhttp.dll[/i], [i]doorstop_config.ini[/i], [i].doorstop_version[/i],
[i]changelog.txt[/i], [i]OC2ControllerIcons_README.txt[/i]. On Linux / Steam Deck
also clear the Launch Options.
[*][b]Remove everything (Mac):[/b] delete [i]BepInEx[/i], [i]libdoorstop.dylib[/i],
[i]run_bepinex.sh[/i], [i].doorstop_version[/i], [i]changelog.txt[/i],
[i]OC2ControllerIcons_README.txt[/i] and clear the Launch Options.
[/list]
Your game and saves stay exactly as they were.

[size=4][b]Compatibility[/b][/size]
[list]
[*]Steam version of Overcooked! 2 (all DLCs).
[*]Tested on Windows. Linux / Steam Deck (Proton) and macOS use the official BepInEx
loaders for those platforms; feedback is welcome.
[*]Each part of the mod loads independently: if a future game update breaks
one feature, the rest keeps working (see BepInEx/LogOutput.log).
[/list]
